# AI 协作日志（AI Log）

说明：下表逐条记录本次重构中 AI 给出的建议与人工判断。每条判断均明确标注「采纳 / 修改 / 拒绝」并给出理由，未做判断的建议不列入。

| 序号 | 场景 | AI 建议 | 人工判断 | 理由 |
|---|---|---|---|---|
| 1 | 清理 vendored GraphRAG（66.5MB / 1057 文件） | 整个 `app/graphrag/` 目录删除 | **修改**：先提取 `settings.yaml` 所需的中文提示词与配置模板到 `graphrag_project/data/`，再删除其余源码、缓存、测试与文档 | 提示词是项目自定义资产，直接删除会让 GraphRAG 能力永久失效 |
| 2 | 修复模块导入崩溃 | 把 `AsyncSqliteSaver` 初始化整体移到 FastAPI lifespan | **修改**：新增 `get_graph()` 在事件循环内惰性编译，startup 调用一次 | 保留模块可被脚本/单测安全导入的能力，同时不丢失 HITL 持久化 |
| 3 | 处理 `app/test/` 下 6 个脚本 | 改造成正式 pytest 用例保留 | **拒绝**：整体删除，另建 `tests/` 编写 25 个自包含用例 | 旧脚本硬编码内网 IP 与数据库密码，且依赖外部服务，不是可复现测试 |
| 4 | 处理 `app/lg_agent/eval/` 评估脚本 | 作为作品亮点保留 | **拒绝**：删除 | 依赖外部标注数据与在线模型，当前无法运行，属于交付范围外 |
| 5 | 处理 `lg_builder_enhanced.py` 与 `lg_agent/main.py` | 保留作为备选实现与 CLI 演示 | **拒绝**：删除 | 无任何引用；CLI 还使用同步 `graph.get_state`，与异步 checkpointer 不兼容 |
| 6 | 处理 GraphRAG 代码依赖 | 连同工具节点一起删除 GraphRAG 相关功能 | **拒绝**：改用 pip 声明的 `graphrag` 包并惰性导入 | 知识图谱问答是作品的核心差异化能力，不能因清理而丢失 |
| 7 | GraphRAG 配置文件 | 在 `settings.yaml` 中直接填入 API Key 便于运行 | **拒绝**：全部改为 `${VAR}` 占位符，由 `IndexingService` 从应用配置注入 | 密钥不得进入仓库；占位符还能让不同机器复用同一份配置 |
| 8 | 数据库初始化脚本 | 保留 `drop_all` + `create_all` 确保表结构最新 | **修改**：只做 `create_all`，失败时 `sys.exit(1)` | 原脚本会清空用户会话数据，且异常被吞掉导致退出码为 0 |
| 9 | 异步测试实现 | 安装 `pytest-asyncio` 并使用 `@pytest.mark.asyncio` | **修改**：使用标准库 `asyncio.run()` | 当前环境未安装该插件；减少交付依赖更利于复现 |
| 10 | 本地 `llm_backend/.env` 处理 | 连同真实密钥一并清空 | **修改**：保留本地文件但修正失效的绝对路径；只对 `.env.example` 脱敏并加入 `.gitignore` | 本地文件是用户运行所需且已被忽略；清空会破坏其现有环境 |
| 11 | 工作区根目录的学习资料（PDF / MD） | 一并删除以精简交付物 | **拒绝**：保持原样 | 它们位于项目目录之外，是用户的面试/学习资料，不属于本次重构范围 |
| 12 | checkpointer 选型 | 换回 `MemorySaver` 简化实现 | **拒绝**：保留 `AsyncSqliteSaver` | 作品卖点之一是人机确认中断可跨重启恢复，内存版会丢失该能力 |
| 13 | 前端产物 `static/dist/` | 删除，README 中说明前端需自行构建 | **拒绝**：保留编译产物并保留 SPA 回退处理器 | FastAPI 直接托管前端，删除后项目无法一键演示 |
| 14 | 原 README 内容 | 保留并在其后追加新章节 | **拒绝**：整体重写 | 原文把 AssistGen 与另一个 Neo4j 示例项目拼在一起，且端口/文件名描述错误 |
| 15 | 缓存后台清理任务 | 在 `__init__` 中无条件 `create_task` | **修改**：先检测运行中的事件循环，无循环时跳过 | 无循环环境构造服务会抛 `RuntimeError`，并产生未等待协程警告 |
| 16 | 上传文件名 | 信任客户端 `filename` 直接拼接路径 | **修改**：新增 `safe_filename()` 只取 basename | 防止 `../../` 路径穿越导致文件写到预期目录之外 |
| 17 | 启动参数 | 维持 `reload=True`、端口 8000 硬编码 | **修改**：改为 `HOST` / `PORT` / `RELOAD` / `LOG_LEVEL` 环境变量，默认值不变 | 便于部署与自动化验证，同时不改变本地默认体验 |
| 18 | 文档框架 | 只写 README，不写 spec/design/test-record/ai-log/reflection | **拒绝**：按交付标准补齐 5 份文档 | 作品集需要可追溯的需求—设计—测试闭环，README 单独不足以体现工程能力 |
